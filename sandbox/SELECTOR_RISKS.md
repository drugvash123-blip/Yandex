# Уязвимые места разметки Яндекса

Пометки от 13 октября 2026. Это диагностика, а не универсальный новый парсер.

| Место | На что опирается код | Что может сломаться | Как сейчас проявится |
|---|---|---|---|
| Поисковое поле | name=text, input__control, type=search | Новое поле, редактор contenteditable | unexpected_page / submission_failed |
| Запрос и номер страницы | URL-параметры text и p (нумерация с нуля) | Новый формат адреса или AJAX без обновления p | incomplete; не отправляется как отсутствие |
| Карточка результата | serp-item, OrganicTitle-Link, h2 a, organic__url | Новый контейнер/заголовок, другие типы карточек | Неизвестная страница или частичное распознавание |
| Реклама | serp-item_type_ad | Изменение признака рекламы | Возможное попадание рекламы в позиции; отрицательная проверка недостаточна |
| Переход дальше | Числовая ссылка, Pager-Item_type_next, rel=next, «Показать ещё» | Иконка без доступного имени, новый компонент | incomplete либо pagination_stalled |
| Конец короткой выдачи | Видимый Pager/nav, текущий номер и отключённый Next либо понятные номера только назад | Новая структура, отсутствие pager у одностраничной выдачи | incomplete: отсутствие кнопки само по себе не считается концом |
| Пустая выдача | Пока нет подтверждённого отдельного адаптера | Ноль результатов без известных карточек | unexpected_page; безопасно, но такой запрос ещё не считается успешной пустой выдачей |
| CAPTCHA | URL captcha, заголовок, известные элементы CAPTCHA | Новый адрес/компонент/язык | Может классифицироваться как unexpected_page вместо captcha |
| Временная блокировка | HTTP-статус документа и известный текст | HTTP 429 внутри XHR/fetch | Повтор выдачи/остановка пагинации; отдельного анализа HTTP AJAX пока нет |
| Ссылки сайтов | href с прямым доменом | Новый редирект-трекер в выдаче | Домен не сопоставится без разбора редиректной ссылки |

## Границы проверки страниц

Теперь сохранены запрос, ожидаемый номер страницы, количество результатов и
их URL в page_checks. Повтор прежнего набора ссылок не считается новой страницей,
даже если URL страницы изменился. Для «Показать ещё» учитывается изменение
накопленного списка. Частичное совпадение сайтов между страницами допускается.

Эти проверки подтверждают последовательность распознанных результатов, но
не доказывают, что парсер умеет читать каждый возможный тип карточки Яндекса.
Если новый дизайн оставит часть известных элементов, возможна частичная
обработка без явной ошибки. Будущий этап: учёт неопознанных карточек, явный
контракт парсера, сохранённые образцы различных вариантов выдачи.

Конец по распознанной пагинации — проверяемое основание, но не обещание
универсальности. Новый незнакомый элемент Next внутри pager мешает объявить
его последним. Исчезновение всего pager также считается неопределённостью.
Нужны реальные сохранённые образцы короткой и пустой выдачи, прежде чем
расширять правила её окончания. Не следует угадывать конец по отсутствию ссылок.

## Что сделать на будущем этапе

1. Собрать обезличенные HTML-примеры desktop/mobile, короткой/пустой выдачи,
   разных языков, рекламы, «Показать ещё» и CAPTCHA.
2. Вынести распознавание формы, карточек и пагинации в отдельный адаптер.
3. Использовать доступные роли/имена и состояние элементов вместе с DOM-признаками.
4. Добавить контроль неполного распознавания карточек и ответов AJAX.
5. При неизвестном дизайне сохранять диагностику и возвращать incomplete,
   вместо попыток случайных кликов или ложного «сайт отсутствует».

### Исправление блока картинок

Карточки с заголовком `.UniSearchHeader-Title` исключаются из `RESULT_LINKS`
целиком: вложенные ссылки/картинки также не занимают позицию сайта. Этот же
селектор используется при ожидании выдачи, извлечении и проверке пагинации.
Обычные результаты с доменами Яндекса остаются в списке — фильтрации по одному
лишь домену нет. Запасные h2/organic__url и один заголовок на карточку сохранены.

Добавлена переносимая локальная регрессия с вертикальным блоком, рекламой,
дублирующей ссылкой, запасным заголовком и обычным результатом yandex.ru.
Отдельный offline replay проверяет сохранённый живой DOM: 10 сайтов,
dms-spb.ru восьмой, индекс ссылки для клика соответствует именно целевому сайту.
Replay пропускается, если приватный артефакт отсутствует в другом checkout.
Скрипты и интернет при разборе сохранённой выдачи отключены.

Это исключение подтверждено для наблюдавшегося блока. Другие блоки без
такого заголовка и будущие изменения классов требуют отдельной диагностики.

Проверка после исправления: полный sandbox — 111 passed, 3 xfailed
(известные дефекты старого кода), 175,42 секунды. Offline replay прошёл,
не был пропущен: сохранённая живая выдача подтверждает позицию 8.
