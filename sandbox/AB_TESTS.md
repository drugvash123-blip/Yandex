# Последовательные прогоны поиска

Цель пользователя: пять успешных прогонов подряд для запроса
«мебель из массива сосны» с переходом на dms-spb.ru.
Тесты используют Webshare; CAPTCHA проходит пользователь.

Критерий: status=found с подтверждённым visited_url целевого домена
или status=not_found после полной проверки пяти страниц органической выдачи.
В обоих случаях требуется отсутствие ошибок навигации, обработки выдачи и HTTP 429. Восстановление после 429
считается функциональным восстановлением, но не чистым успешным прогоном.
Ручная CAPTCHA на первом запросе допустима. Ошибка сбрасывает серию.
not_found после пяти страниц подтверждает отсутствие сайта только в проверенных
результатах, а не во всей выдаче. По уточнению пользователя такой прогон считается
успешным. Преждевременное завершение пагинации до пяти страниц не засчитывается.

Предлагаемое сравнение: A — 15 секунд просмотра выдачи, B — 30 секунд.
Прокси, запрос, домен, интервал ввода и время на целевом сайте одинаковые.
Для сравнения нужны отдельные постоянные профили; накопление сессии и
изменение серверных ограничений остаются возможными смешивающими факторами.
Вариант сравнения подтверждён пользователем; уже начат один базовый
прогон с прежним профилем, его нельзя выдавать за контролируемое A/B-сравнение.
