# Наблюдение CAPTCHA поиска — 13 октября 2026

Один поиск «мебель из массива сосны» через Webshare в новом отдельном профиле
captcha-observation-webshare. Платный решатель не использовался.
Артефакты: sandbox/artifacts/3f2822d49a93409fb479ad5a10f0623e.

## Что подтверждено

Сначала показан флажок на ya.ru/showcaptcha, в основной странице без iframe.
Пользователь нажал его вручную. Появилась задача AdvancedCaptcha_silhouette:
нужно выбирать объекты по образцу порядка. Поля текстового ответа нет.

| Элемент | Наблюдаемая структура |
|---|---|
| Контейнер задания | .AdvancedCaptcha.AdvancedCaptcha_silhouette |
| Область изображения | .AdvancedCaptcha-View / .AdvancedCaptcha-ImageWrapper, img с alt «Задание с картинкой» |
| Образец порядка | .AdvancedCaptcha-SilhouetteTask, TaskImage-Img и TaskImage-Canvas |
| Кнопка отправки | .CaptchaButton_view_action |
| Текстовое поле | Отсутствует |
| Размещение | Основная страница; iframe отсутствует |

Это подтверждает общий набор классов со старым кодом и демо, но другой тип
задания и другую область поиска элементов. Не следует использовать правила
текстового демо автоматически для задачи с силуэтами.

## Захват и безопасность кликов

Первый снимок advanced-формы был сделан до загрузки картинок и оказался пустым.
Полностью отрисованная задача сохранилась в конечном page.png.
Исправлен наблюдатель: учитываются complete/naturalWidth/naturalHeight и хеш
источника изображения. Смена загрузки или изображения создаёт новую запись.
Полный URL источника в структурный JSON не записывается. HTML/снимки по-прежнему
содержат исходные данные страницы и находятся только в ignored-артефактах.

Для задачи с порядком важен образец инструкции, а не только основная картинка.
Однако область снимка не должна автоматически считаться областью кликов:
на снимке карточки могут оказаться инструкции и кнопки.
Challenge.click_area_selector задаёт отдельную разрешённую область.
Все координаты валидируются до первого клика. Хотя бы одна координата вне
картинки приводит к отказу без частичного выполнения/нажатия Submit.

Локально проверены допустимая координата и ответ с первой допустимой,
но второй выходящей в область инструкции: во втором случае нет ни одного клика.
Проверен поздно загружаемый образец изображения и отсутствие URL источника
в структурном JSON. Выборка CAPTCHA/таймаутов/наблюдения: 42 passed in 23.69s.

## Состояние после ожидания

За отведённые 15 минут CAPTCHA не была завершена; результат исходного поиска
captcha, pages_checked=0. Это ожидаемая остановка ручного наблюдения, не сбой
платного сервиса. Окно сохранено для ручной проверки, runner больше не кликает
и не листает страницы. Пользователь получил просьбу пройти задачу вручную
и сообщить, открылась ли выдача, 429 или новая CAPTCHA.
До ответа подтверждение успешного прохождения этого задания отсутствует.

Параметры/качество распознавания силуэтов у CapGuru пока не проверены.
Новый адаптер не подключён к поисковому runner. Следующий шаг — подтвердить
состояние реального поиска после ручного прохождения, затем выбрать один
поддерживаемый тип для ограниченного живого теста с согласованной стоимостью.
