# Проверка полноты поиска — 13 октября 2026

## Что изменилось

Runner проверяет, что URL выдачи содержит заданный запрос и ожидаемый номер
страницы. «Показать ещё» не требует смены номера, но требует изменения
накопленного набора результатов. Повтор прежнего набора сайтов не считается
новой страницей, включая перестановку тех же ссылок.

После клика перехода программа ждёт изменения результатов, а не только URL.
Это проверено на примере, где адрес уже сменился, а старая выдача остаётся
видимой ещё секунду. Результаты каждой проверенной страницы записываются
в page_checks вместе с номером и количеством карточек.

| Ситуация | Результат |
|---|---|
| Целевой результат найден | found; для --click подтверждается переход |
| Лимит страниц проверен | not_found, search_complete=true, page_limit |
| Подтверждён последний pager раньше лимита | not_found, search_complete=true, end_of_results |
| Переход отсутствует, конец неизвестен | incomplete |
| Выдача не обновилась | pagination_stalled |
| URL относится к другому запросу/номеру | incomplete |
| Нет распознаваемых карточек | unexpected_page; не делается вывод о пустой выдаче |
| CAPTCHA/HTTP-ошибка | Соответствующий отказ, а не отсутствие сайта |

Последний pager подтверждается видимым текущим номером и отключённым Next
либо распознанными номерами без последующих страниц/других активных элементов
перехода вперёд. Незнакомые активные элементы внутри pager мешают объявить конец.
Отсутствие всего pager не является доказательством последней страницы.

completed_search принимает подтверждённую короткую выдачу как успешный прогон.
TaskService.submit принимает not_found только с явной полнотой и допустимой
причиной завершения. Старые результаты без подтверждения не отправляются
автоматически — нельзя задним числом считать их проверенными.

Получен not_found, search_complete=true, completion_reason=page_limit;
код выхода 0. CAPTCHA не понадобилась, HTTP-ошибок основных навигаций не было.
Были фоновые предупреждения прокси. Статистика этого теста в prstar не отправлялась.

Это не повторная живая серия 5/5: прежняя серия относится к предыдущей версии проверки страниц.
Реальные короткая и пустая выдачи требуют сохранения образцов и отдельной
проверки. Неизвестные варианты пока безопасно остаются неопределёнными.

## Следующие шаги

1. Проверить новые условия на живой выдаче; собрать реальные образцы её конца
   и отсутствия результатов, не угадывая их по отсутствию карточек.
2. Протестировать получение и приём отчётов prstar на реальных тестовых заданиях.
3. Разобрать CAPTCHA-код отдельно.
