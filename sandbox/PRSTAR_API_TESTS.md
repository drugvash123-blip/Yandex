## Изменение кода и локальные проверки

TaskService.post теперь сохраняет last_response до raise_for_status.
Таким образом, при 4xx/5xx сохраняются статус и текст ошибки, а не только
название исключения. Регрессия проверяет сохранение ответа 503/Unavailable.
Актуальный набор test_task_service.py: 7 тестов прошли.
Один первоначальный локальный запуск был заблокирован sandbox при создании
HTTP-сервера; повтор с нужным разрешением прошёл. Это не отказ prstar.

Подтверждены локально multipart-поля, разбор непустого списка, отправка found,
подтверждённый not_found, запрет отправки CAPTCHA и неполного not_found,
отличие HTTP-ошибки от пустой очереди.
